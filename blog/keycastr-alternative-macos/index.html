KeyCastr Alternative for Mac — HoverBoard Keystroke Display

Looking for a KeyCastr alternative for Mac? KeyCastr is the classic open-source keystroke visualizer: it shows the keys you press so viewers can follow shortcuts in tutorials and conference talks. HoverBoard includes Keystroke Display as one mode inside a broader presentation toolkit — draw, spotlight, freeze, whiteboard, cursor halo, and more.

If all you need is a free, focused key HUD, KeyCastr remains an excellent utility. If you want keystrokes plus the rest of a teaching overlay, HoverBoard is the alternative that keeps everything in one menu bar app.

What KeyCastr does well

KeyCastr’s reputation comes from doing one thing cleanly:

  • Display pressed keys and chords during demos
  • Stay lightweight and open source
  • Work for coding talks, shortcut tours, and streamed tutorials
  • Avoid forcing a larger presentation suite

If your recording setup already has annotation elsewhere (or you never draw on screen), KeyCastr is often enough.

What HoverBoard Keystroke Display adds

HoverBoard’s Keystroke Display (default ⌃⌥K) shows modifier chords and shortcuts as a live HUD while you present. It is built for the same tutorial moment as KeyCastr, with a few product differences:

  • Ships beside Draw, Spotlight, Freeze, Whiteboard, Cursor Halo, Notes, Sessions, and Break Timer
  • Asks for a privacy confirmation before first use because keyboard observation is sensitive
  • May require Input Monitoring permission on macOS
  • Renders locally; HoverBoard has no backend for your key events
  • Should be turned off before typing passwords or secrets

Full walkthrough: How to use HoverBoard Keystroke Display.

When the broader toolkit matters

Many “show my shortcuts” sessions also need:

  • Circling a UI control (Draw)
  • Making the cursor obvious (Cursor Halo / Spotlight)
  • Pausing a changing IDE (Freeze)
  • Sketching a data flow (Whiteboard)

HoverBoard exists so you do not juggle four single-purpose apps mid-lesson.

Which should you use?

Choose KeyCastr if you want a free, open-source, keystroke-only HUD.

Choose HoverBoard if you want a KeyCastr alternative for Mac that covers keystrokes and the surrounding teaching workflow in one native app.

Pro is $15.99 one-time, with a 60-second trial on Keystroke Display and other Pro tools each time you open them.

Download HoverBoard and press ⌃⌥K the next time a shortcut is the lesson.
