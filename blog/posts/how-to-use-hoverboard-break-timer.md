Break Timer puts a visible countdown over your screen so a promised five-minute break stays five minutes. It is designed for workshops, online classes, training sessions, office hours, and any presentation where the audience needs to know when to return.

## Start a timer

The default shortcut is **⌃⌥T**. You can also start it from the menu bar. Choose a duration, then pick the visual style that fits the room:

- **Fullscreen** makes the countdown impossible to miss during a group break.
- **Minimal** keeps a small timer in the corner while you prepare the next section.

Set a custom message such as “Back at 14:30”, “Stretch break”, or “Questions at 3:15”. The message gives the number context, especially when the timer is visible in a shared screen or recording.

## Control the countdown while presenting

The timer toolbar supports pause/resume and adding time. The keyboard shortcuts are:

| Shortcut | Action |
| --- | --- |
| **P** | Pause or resume |
| **M** | Add one minute |
| **Esc** | Close the timer |

Add a minute when the group is still in conversation. Pause when a technical issue interrupts the break. These small controls are better than restarting a timer and making the end time ambiguous.

## Use an end chime thoughtfully

An optional chime signals the end without requiring everyone to keep watching the screen. Turn it off for recordings, quiet study sessions, or environments where an audio cue would be disruptive. The message and visual countdown remain useful without sound.

## A workshop workflow

1. Announce the exact return time verbally.
2. Press **⌃⌥T** and set the matching duration.
3. Use the fullscreen style while participants leave their desks.
4. Keep the timer visible if you are preparing slides or notes.
5. Press **M** only when you intentionally extend the break.
6. Resume with the next section when the countdown ends.

Because the timer is an overlay, you do not need to open a clock app or share a second window. The underlying presentation remains available beneath it.

## Break Timer is free forever

Break Timer is one of HoverBoard’s free tools. It does not start the 60-second Pro preview and does not require a license. Global hotkeys, custom messages, pause, add-minute, display styles, and the optional chime are part of the timer workflow.

## Troubleshooting

If **⌃⌥T** does nothing, grant Accessibility permission to HoverBoard and check Settings → Hotkeys for conflicts. If the timer is hidden behind another window, use the fullscreen style or close and reopen it from the menu bar. If the chime is not audible, check the Mac output volume and confirm the chime option is enabled.

The best timer is the one nobody has to ask about. Put it on screen, make the end time visible, and keep the session moving.
