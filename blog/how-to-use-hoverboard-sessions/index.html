How to Use HoverBoard Sessions — Build a Deck While You Present

Sessions turns a live presentation into a useful artifact. Save important frames from Draw, Freeze, or Whiteboard as you teach, then organize them into a local library and export the finished sequence as images or a multi-page PDF.

What a Session contains

A Session is a named collection of presentation frames. Each frame represents the visible work at a useful moment: an annotated slide, a frozen explanation, or a whiteboard state. Sessions stay on your Mac; there is no cloud account and no automatic upload.

This makes Sessions useful for:

  • Sending a workshop recap after class.
  • Keeping a record of a system-design discussion.
  • Building a visual lesson handout without stopping to edit slides.
  • Collecting the best frames from a live product demo.

Capture a frame

Use Save to Session in the toolbar while Draw, Freeze, or Whiteboard is active. In Draw, save the visible annotations over the live screen. In Freeze, save the stable snapshot and its explanation. In Whiteboard, save the board view you want to include in the sequence.

The capture action is deliberately close to the presenting tools. You do not need to leave the mode, open a screenshot app, or remember a filename while speaking.

Organize the library

Open the Sessions browser from the menu bar or the Session entry point in HoverBoard. Create a Session before a class or create one when a useful thread begins. Rename it with a clear title such as “API review — July 23” or “Lesson 04 — joins”.

In the browser you can:

  • Reorder frames by dragging them into the teaching sequence.
  • Rename the Session after the conversation becomes clearer.
  • Review thumbnails before exporting.
  • Remove accidental captures and keep only the frames worth sharing.

Treat the library as a rough edit: it is faster to capture generously and clean up afterward than to interrupt an explanation searching for the perfect screenshot.

Export PNG or PDF

Export an ordered PNG set when each frame will be used separately in slides, documentation, or a design handoff. Export a multi-page PDF when the result should read as a compact recap or handout. The order in the Session browser becomes the order in the export.

Check the first and last frame before exporting. A useful sequence usually has a clear opening state, one frame per major idea, and a final state or summary.

A practical workflow

  1. Create a Session named for the meeting, class, or demo.
  2. Use Draw for live callouts and save the frames that explain a key point.
  3. Use Freeze when the live app is too dynamic to explain clearly.
  4. Use Whiteboard for a diagram or mindmap, then save the board view.
  5. Reorder the frames after the presentation.
  6. Delete duplicates and rename the Session if necessary.
  7. Export PNG files or a PDF and share the result intentionally.

Sessions are not a replacement for a source-of-truth document. They preserve the visual explanation that happened during the presentation; keep editable slides, code, or a Whiteboard export alongside them when the audience needs to continue working.

Privacy and storage

Frames, names, and exports are local data. HoverBoard does not send screen contents to a server. Export only when you choose to, and store the resulting PNGs or PDF wherever your workflow requires.

Pro access

Sessions are a Pro feature. Freeze, Whiteboard, and other Pro tools can be previewed for 60 seconds, but unlimited Session capture and export require Pro. Draw, Spotlight, and Break Timer are free forever.

Troubleshooting

If Save to Session is missing, verify that you are using Draw, Freeze, or Whiteboard and that the Pro trial/license is active. If a frame is out of order, drag it in the browser before exporting. If the PDF does not match the intended narrative, inspect the thumbnail order and remove duplicate captures.

The best Session is not a recording of everything. It is the small, ordered set of frames that lets someone understand the explanation after the call ends.
