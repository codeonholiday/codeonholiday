How to Use HoverBoard Screenshot — Capture a Region or Full Display

Screenshot captures a still image of your display without leaving your presentation flow. Drag a region, grab the full screen, then copy, save, or annotate before you share the file.

Start a capture

The default shortcut is ⌃⌥G. You can also start from the menu bar.

  1. A dim overlay appears over the display under your pointer.
  2. Drag to select a region, or press Space or Enter to capture the full display.
  3. Press Esc to cancel.

HoverBoard needs Screen Recording permission the first time you capture. Allow it in System Settings if macOS prompts you.

After capture — Copy, Save, or Edit

A small HUD appears with three actions:

  • Copy — paste into Slack, docs, or email.
  • Save — write a PNG to disk.
  • Edit — open the built-in editor before you copy or save.

Screenshot editor

The editor supports:

  • Crop — trim the capture before export.
  • Pen, arrow, rectangle — mark up the image.
  • Text — add labels or callouts.

Use the toolbar colors and undo when you need a quick annotation. Done returns you to the HUD; Save or Copy exports the edited image.

Screenshot is free forever

Screenshot does not start the 60-second Pro preview and does not require a license. Region capture, full-display capture, copy, save, and the basic editor are included in the free download.

Troubleshooting

If ⌃⌥G does nothing, grant Accessibility to HoverBoard and check Settings → Hotkeys for conflicts. If capture fails, confirm Screen Recording is allowed for HoverBoard in System Settings → Privacy & Security. If Space/Enter does not capture the full display, click the overlay once so it has focus, then try again.
