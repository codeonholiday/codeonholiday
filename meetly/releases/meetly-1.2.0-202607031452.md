# Meetly 1.2.0

## What's New

### Per-calendar reminder rules
- Customize each monitored calendar independently: toggle the fullscreen reminder overlay and the reminder sound on or off.
- Limit how many times the sound repeats before it stops (1 / 3 / 5 / Always). The default stays on **Always**, so reminders keep their familiar behaviour until you change it — handy when the sound is useful but gets annoying if it goes on too long.

### iCloud sync for rules (Pro)
- Your per-calendar settings now sync across your Macs via iCloud. A rule set on one Mac automatically applies to the same calendar on every other Mac signed into the same account.

### Remind about plain events (Pro)
- New per-calendar **Events** option: **Meetings only** (default) or **All events**. Choosing "All events" also reminds you about calendar entries with no join link, location, or attendees — like "5pm groceries" — not just meetings.
- Plain-event reminders show a clean **Got it** button instead of Join / Copy Location.
