# Meetly 1.5.2

## What's New

### NEXT remains visible during long events
The menu bar now shows the nearest upcoming meeting under **NEXT** even when a long-running or all-day event is currently shown under **NOW**.

## Compatibility

- Long-running events remain visible as the current event.
- Keyboard navigation and the live NEXT countdown follow the same NOW → NEXT → UPCOMING order.
