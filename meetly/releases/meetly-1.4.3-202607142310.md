# Meetly 1.4.3

## What's New

### Keyboard navigation on the fullscreen reminder
Move between overlay actions with ← / → / ↑ / ↓, activate the focused button with Enter, and dismiss with Esc — the same Carbon hotkey path as the menu bar and quick panel, so it works in the agent (LSUIElement) overlay.

### Fix: Enter after dismissing the overlay
Closing the reminder no longer leaves a global Return hotkey armed from the menu bar, so Enter outside Meetly will not open a leftover selected meeting.

## Compatibility

- Calendar monitoring, reminder rules, iCloud sync, and the quick panel shortcut are unchanged.
