# HoverBoard 1.3.17

## Fixed

- **Stable labeled shapes.** Editing text after manually resizing a shape no longer shrinks the shape back around its label.
- **Correct label alignment.** Text now uses the full inner width of its shape, so left and right alignment respect the shape padding.
- **Independent text color.** Labeled shapes expose a dedicated text color control; changing the shape stroke no longer changes its label color.

These fixes apply to both Freeze and Whiteboard.
