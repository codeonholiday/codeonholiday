# HoverBoard 1.3.14

## New

- **Whiteboard presentation modes.** Switch between fullscreen and a popup window.
- **Movable, resizable popup.** Drag the popup to any position and resize it with native window controls.
- **Quick whiteboard controls.** Zoom in/out, view the current zoom percentage, reset the viewport, toggle the grid, and switch between fullscreen and popup modes.
- **State preservation.** The canvas and model remain intact when switching presentation modes.
- **Whiteboard popup chrome.** The popup has a “Whiteboard” title, shadow, and stays above other windows.
