# HoverBoard 1.3.5

## Fixed

- **Mindmap trees arrange as you build.** New child and sibling nodes auto-layout, and connectors hug node edges more cleanly.
- **Labeled shapes no longer jump taller on a single line.** Typing in a rectangle, ellipse, or diamond keeps height stable until you add another line.
- **Return inside a labeled shape no longer freezes the app.** Multi-line edits grow the shape with each new line instead of locking up.
