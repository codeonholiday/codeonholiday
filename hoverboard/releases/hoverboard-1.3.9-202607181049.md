# HoverBoard 1.3.9

## Improved

- **Faster draw fade presets.** Auto-fade now includes **1s** and **2s** options (slider range starts at 1 second).
- **Toolbar settings dismiss on outside click.** Draw, Halo, Spotlight, Break Timer, and Keystroke settings close when you click outside the panel — not only when tapping the gear again.
- **Keystroke Display chords.** Holding modifiers and keys updates a single live chip (e.g. ⌘ → ⌘C) instead of stacking overlapping chips. Simultaneous keys show as `A + S`.

## Fixed

- **Draw mode no longer dims the screen.** Enabling Draw keeps the display at full brightness.
- **Keystroke Display shows app and global shortcuts.** Uses a listen-only event tap (plus Input Monitoring permission) so menu shortcuts and system hotkeys appear on screen.
