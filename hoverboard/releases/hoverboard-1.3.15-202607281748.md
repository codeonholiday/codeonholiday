# HoverBoard 1.3.15

## New

- **Multi-display overlays.** Cursor Halo and Spotlight now follow the active display across extended desktop setups.
- **A canvas for every display.** Draw creates an independent canvas on each connected screen, so annotations stay on the display where they were drawn.
- **Active-display controls.** The Draw toolbar, settings, and trial indicator follow the display currently in use.

## Improved

- Drawing history, undo, redo, clear, and export operate on the active display's canvas.
- Screen coordinate handling now supports displays positioned to the left, right, above, below, or offset from the primary display.
