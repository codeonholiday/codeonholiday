# HoverBoard 1.3.3

## Added

- **Mindmap in Whiteboard.** Build topic trees with child and sibling nodes, collapse branches, and arrange layouts on demand (tree or radial).
- **Mindmap keyboard shortcuts.** Tab adds a child node, Return adds a sibling, and ⌘⇧L rearranges the tree.
- **Mindmap templates.** Start from a Lesson Outline or Concept Map preset.
- **On-canvas shortcut hint.** When a board has mindmap nodes, the toolbar shows Tab / Return / arrange shortcuts.
